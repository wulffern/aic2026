\subsection{I get asked for password when I access
github}\label{i-get-asked-for-password-when-i-access-github}

It's likely because the remote is set to https and not SSH

\begin{verbatim}
$git remote -v
origin https://github.com/analogicus/lelo_gr01_sky130a.git
\end{verbatim}

then do

\begin{verbatim}
git remote set-url origin git@github.com:analogicus/lelo_gr01_sky130a.git
\end{verbatim}

Or it could be because you have not setup public/private key access to
github.
