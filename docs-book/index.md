# Advanced Integrated Circuits

Lecture notes for *TFE4188 Advanced Integrated Circuits*, NTNU.

Pick a chapter in the sidebar, or read straight through - the chapters
are ordered the way the course runs, from physics up to systems. The
same material exists as a [PDF book](/aic2026/assets/aic.pdf), an
[EPUB](/aic2026/assets/aic.epub), and per-lecture slide decks linked at
the top of each chapter.

If you find an error, fork the
[repository](https://github.com/wulffern/aic2026), fix the lecture
source, and create a pull request.
