WHAT YOU ARE LOOKING AT

A first order infinite impulse response filter is one line of code: y[n] = b*x[n-1] + a*y[n-1]. Each output is a scaled copy of the previous input plus a scaled copy of the previous output, and it is that second term — the feedback — that makes the impulse response infinite and puts a pole in the transfer function

H(z) = b·z-1 / (1 − a·z-1)

with a zero at the origin and a pole at z = a. On the z-plane panel the circle is |z| = 1; the filter is stable as long as the pole stays inside it. The bottom middle panel is the measured output spectrum, and the yellow trace is |H(f)| evaluated straight from b and a — they should lie on top of each other, which is a good way to convince yourself that the loop and the algebra agree.

THINGS WORTH TRYING

  • Leave a = 1, which is what the script does. The pole is exactly on the unit circle, the DC gain is infinite, and the output wanders: this is an accumulator, not a filter that settles. It still attenuates high frequencies at 20 dB/decade, which is what the plot in the lecture shows.
  • Pull a down to 0.99, 0.9, 0.5. The pole moves in, the DC gain becomes finite at b/(1−a), and the corner frequency ≈ (1−a)/2π moves up. At a = 0 there is no feedback left and you have a one-sample delay with gain b.
  • Set f_1 low, around bin 100. The tone now sits in the passband and comes through with the DC gain instead of being attenuated. Compare the input and output spectra: the noise above the corner has dropped, the tone has not.
  • Set the sampling period P to 1 to remove the pulse train. The images vanish and you see the filter on its own, which makes the 20 dB/decade roll-off easy to read off the right-hand panel.

THE PYTHON

#- IIR filter
b = 0.3
a = 0.25
z = a + 1j*b
z_abs = np.abs(z)
y = np.zeros(N)
y[0] = a
for i in range(1,N):
    y[i] = b*x_sn[i-1] + y[i-1]

Source: ex/iir.py. Note that a is computed but never multiplied into y[i-1], so the script really runs with a = 1. This page makes that coefficient a slider so you can see what it was meant to do. There are faster ways to do this in Python; see scipy.signal.iirfilter.
