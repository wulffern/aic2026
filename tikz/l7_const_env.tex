% Constant envelope transmitter: everything is in the phase.
%
% The modulation goes into the oscillator and nothing touches the
% amplitude, so the power amplifier only ever sees one signal level and
% can be run in compression, which is where it is efficient. That is the
% whole argument for GFSK in a battery powered radio, and it is why this
% figure has so little in it.
