% Fully differential two-stage OTA with parallel common mode feedback,
% redrawn from media/diff_ota.png. Only one side of the OTA is drawn,
% as in the original. Sizes are "WFLF": 24F4F means W = 24 and L = 4
% minimum gate lengths, in red like the hand original.
%
% Left: the CMFB amplifier - VON/VOP sensed through 60k||20f networks
% into a differential pair against a 100k/100k mid-supply reference,
% PMOS diode loads, and the diode node drives the gate of one of the
% two top PMOS in the first stage load (the other is VBP biased).
% Middle: VBP/VCP cascoded tail, PMOS input pair, NMOS diode load.
% Right: cascoded mirror (VCN) up to the first stage output X, second
% stage driver with VBP1 load, and 500f cascode compensation. The X
% route crosses the 500f wire without a dot, as in the original.
